DEBUPA - INSTRUCCIONES ACTUALIZADAS PARA INICIAR EL PROYECTO
==============================================================

Estas instrucciones son para iniciar DEBUPA desde una terminal nueva de PowerShell.
No abras el HTML directamente: el frontend y la API deben servirse juntos desde Uvicorn.

Las variables $env: solo duran mientras esta terminal esté abierta. No pegues cadenas
con contraseñas en GitHub, capturas ni chats.

1. UBICARSE EN EL PROYECTO
--------------------------
cd "C:\Users\juanf\Downloads\Trabajo Programación\sena-oportunidades"

Si recibiste cambios nuevos:
git pull origin main

2. CREAR O ACTIVAR EL ENTORNO VIRTUAL
-------------------------------------
Si .venv todavía no existe:
python -m venv .venv

Activa el entorno:
.\.venv\Scripts\Activate.ps1

Si PowerShell bloquea Activate.ps1, ejecuta solo para esta terminal:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Después vuelve a ejecutar:
.\.venv\Scripts\Activate.ps1

3. INSTALAR DEPENDENCIAS
------------------------
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-postgresql.txt
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Resolve-Path '.venv').Path 'ms-playwright'
.\.venv\Scripts\python.exe -m playwright install chromium

4. CONFIGURAR POSTGRESQL DE SUPABASE
------------------------------------
En Supabase abre Connect, elige Session pooler y copia la cadena completa.
Debe incluir un usuario postgres.TU_PROJECT_REF y la contraseña actual.

$env:DEBUPA_BASE_DATOS = "PEGA_AQUI_LA_CADENA_COMPLETA_DE_SUPABASE"

Si comienza por postgresql://, conviértela:
$env:DEBUPA_BASE_DATOS = $env:DEBUPA_BASE_DATOS -replace "^postgresql://", "postgresql+psycopg://"

Si no tiene ?, agrega:
$env:DEBUPA_BASE_DATOS += "?sslmode=verify-full"

Si ya tiene ?, agrega:
$env:DEBUPA_BASE_DATOS += "&sslmode=verify-full"

Si la contraseña tiene caracteres especiales, codifícalos para una URL. No cambies
el usuario, servidor ni puerto de Supabase.

Indica la ruta del certificado CA descargado desde Supabase:
$env:PGSSLROOTCERT = "C:\Users\juanf\Downloads\prod-ca-2021.crt"

Comprueba sin imprimir la cadena completa:
$env:DEBUPA_BASE_DATOS.StartsWith("postgresql+psycopg://")
$env:DEBUPA_BASE_DATOS -match "^postgresql\+psycopg://postgres\.[a-z0-9]+:"
$env:DEBUPA_BASE_DATOS -match "sslmode=verify-full"
Test-Path $env:PGSSLROOTCERT

Los cuatro comandos deben devolver True.

5. CONFIGURAR GOOGLE OAUTH
--------------------------
En Google Cloud usa un cliente OAuth de tipo Aplicación web. Para el uso local,
registra exactamente esta URI autorizada:
http://127.0.0.1:8000/api/v1/autenticacion/google/callback

Configura los valores en esta terminal, sin escribirlos en archivos del repositorio:
$env:DEBUPA_ENTORNO = "desarrollo"
$env:DEBUPA_SGVA_ACTIVO = "true"
$env:GOOGLE_CLIENTE_ID = "PEGA_AQUI_TU_CLIENT_ID"
$env:GOOGLE_CLIENTE_SECRETO = "PEGA_AQUI_TU_CLIENT_SECRET"
$env:GOOGLE_URI_REDIRECCION = "http://127.0.0.1:8000/api/v1/autenticacion/google/callback"
$env:GOOGLE_URL_INICIO = "/#inicio"
$env:DEBUPA_CORREO_ADMIN = "debupawebapp@gmail.com"
$env:DEBUPA_SECRETO_SESION = ((New-Guid).Guid + (New-Guid).Guid).Replace("-", "")

Para activar el análisis de IA, crea una clave de Gemini API en Google AI Studio
(es distinta del cliente OAuth de Google Cloud). Configúrala solo en esta terminal:
$env:GEMINI_API_KEY = "PEGA_AQUI_TU_CLAVE_DE_GEMINI"

La opción de IA aparecerá en el formulario y cada aprendiz deberá marcar su
autorización para esa búsqueda. Sin clave o sin autorización, las ofertas se
consultarán igualmente y quedarán pendientes de análisis. El nivel gratuito de
Gemini puede usar los textos enviados para mejorar productos de Google. No se
envían documento, contraseña SGVA, correos ni teléfonos; tampoco el mensaje ni
los adjuntos. La cuota gratuita puede impedir completar algunas clasificaciones.

6. CONFIGURAR LA CLAVE DE CIFRADO
----------------------------------
Protege el permiso de Gmail, los borradores y los comprobantes de pago. La primera vez genera una
clave y guárdala en un gestor de contraseñas:
.\.venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

En cada terminal usa exactamente la misma clave guardada:
$env:DEBUPA_CLAVE_CIFRADO = "PEGA_AQUI_LA_CLAVE_GUARDADA"

No generes una nueva si ya existen conexiones de Gmail o borradores cifrados.

7. ACTUALIZAR LA BASE DE DATOS
------------------------------
Aplica las migraciones pendientes. Ejecutar upgrade head otra vez es seguro:
.\.venv\Scripts\python.exe -m alembic -c backend\alembic.ini upgrade head
.\.venv\Scripts\python.exe -m alembic -c backend\alembic.ini current
.\.venv\Scripts\python.exe -m alembic -c backend\alembic.ini check

current debe mostrar 0010_segundo_navegador_sgva (head).
check debe terminar con No new upgrade operations detected.

8. INICIAR EL SERVIDOR
----------------------
.\.venv\Scripts\python.exe -m uvicorn backend.aplicacion.principal:aplicacion --host 127.0.0.1 --port 8000

Mantén esta terminal abierta mientras usas la aplicación.
En Windows, no agregues --reload: impide que Playwright abra Chromium.
Si cambias el código, detén el servidor con Ctrl+C y vuelve a iniciarlo.

9. ABRIR DEBUPA
---------------
Aplicación: http://127.0.0.1:8000/
Documentación técnica: http://127.0.0.1:8000/docs

Inicia sesión con «Entrar con Google». La prueba local de Gmail envía un mensaje
fijo únicamente a tu propia cuenta. Con DEBUPA_SGVA_ACTIVO=true, las campañas
consultan SGVA. Si configuraste GEMINI_API_KEY, puedes autorizar el análisis de
coincidencias. Al revisar las ofertas, «Revisar envío» muestra el mensaje y cada
destinatario. Solo el botón final «Confirmar y enviar» manda correos reales a las
empresas desde tu Gmail. Puedes cerrar el navegador; mantén el servidor abierto.
Si Gmail deja un envío sin confirmar, revisa «Enviados» antes de volver a contactar.

SEGUNDO NAVEGADOR SGVA (opcional)
En otra terminal de PowerShell, entra al proyecto y configura la misma
DEBUPA_BASE_DATOS y PGSSLROOTCERT del paso 4. Después puedes usar:
.\.venv\Scripts\python.exe -m backend.aplicacion.consola_navegadores activar
.\.venv\Scripts\python.exe -m backend.aplicacion.consola_navegadores estado
.\.venv\Scripts\python.exe -m backend.aplicacion.consola_navegadores desactivar
El primero siempre funciona; el segundo está apagado inicialmente. No es
necesario reiniciar Uvicorn al activarlo o desactivarlo.

Antes del primer envío real, vincula el correo que enviará los resúmenes:
1. Si Google OAuth está en «Prueba», añade debupawebapp@gmail.com como usuario de prueba.
2. En una ventana privada, entra a DEBUPA con debupawebapp@gmail.com y concede Gmail.
3. Abre «Administración»: debe aparecer «Permiso guardado».
   Pulsa «Probar envío propio» y comprueba Recibidos y Enviados de esa cuenta.
4. Ahora sí puedes cerrar sesión. DEBUPA conserva solo el permiso cifrado de
   su cuenta administradora; el aprendiz conserva el cierre de sesión habitual.
5. Entra con la cuenta del aprendiz. El resumen llega solo después de una
   campaña real confirmada, no al iniciar sesión.
Si la prueba falla, revisa que GOOGLE_CLIENTE_ID, GOOGLE_CLIENTE_SECRETO y
DEBUPA_CLAVE_CIFRADO sean los mismos con que se autorizó la cuenta. Entra de
nuevo con DEBUPA si Google dejó de aceptar su permiso. Una notificación de
decisión premium no confirmada queda visible en Administración.

PAGO PREMIUM: $8.000 COP por tres meses contados desde la aprobación manual (precio de referencia: $10.000 COP; descuento del 20%).
El aprendiz adjunta una imagen PNG o JPG de hasta 2 MB. El administrador debe
comprobar el movimiento real en Nequi antes de aprobar. La imagen permanece
cifrada y se borra de la base activa después de la decisión.

10. DETENER EL SERVIDOR
-----------------------
En la terminal donde está Uvicorn, presiona Ctrl + C.

PROBLEMAS FRECUENTES
--------------------
- «DEBUPA_BASE_DATOS no configurada»: repite el paso 4 en la misma terminal de
  Alembic y Uvicorn.
- Error de certificado: verifica que PGSSLROOTCERT apunte a un archivo existente y
  que la cadena use sslmode=verify-full.
- redirect_uri_mismatch: la URI de Google Cloud debe coincidir exactamente con
  GOOGLE_URI_REDIRECCION.
- «No module named alembic»: activa .venv y repite el paso 3.
- Página incorrecta: abre http://127.0.0.1:8000/, no frontend/index.html ni un
  servidor separado para el frontend.
- Si cambiaste de terminal, repite los pasos 4, 5 y 6 antes de migrar y levantar Uvicorn.
