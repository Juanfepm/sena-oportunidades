# SENA Oportunidades

Aplicación web para ayudar a aprendices del SENA a identificar oportunidades compatibles en el SGVA, revisar los destinatarios seleccionados y gestionar campañas de contacto mediante Gmail.

## Estado

Proyecto en etapa inicial de diseño y construcción del MVP.

## Tecnologías previstas

- HTML, CSS y JavaScript con Vite.
- Python y FastAPI.
- PostgreSQL.
- Playwright con un único trabajador para SGVA.
- Gmail API y autenticación con Google.
- MiniLM multilingüe para clasificación semántica local.

La documentación de instalación y desarrollo se ampliará conforme avance el proyecto.
